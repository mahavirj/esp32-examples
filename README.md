# ESP32 Examples

Standalone example projects for Espressif chips, built with [ESP-IDF](https://github.com/espressif/esp-idf).

| Example | ESP-IDF | Description |
| ------- | ------- | ----------- |
| [crt_bundle_partition](crt_bundle_partition) | v6.1 | Trusted root certificate bundle stored in signed, over-the-air updatable flash partitions instead of the application image |
| [nts_client](nts_client) | v6.1 | Authenticated time synchronisation with Network Time Security (RFC 8915), including AES-SIV-CMAC-256 and AES-128-GCM-SIV built on PSA Crypto |
